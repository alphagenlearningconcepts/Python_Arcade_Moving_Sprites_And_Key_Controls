Core Game Loop Concept

What is delta_time & Why Do We Use It?

1. What is delta_time?

  • It is the exact time (in seconds) between the previous frame and the current frame.
  • At 60 frames per second (FPS), delta_time is about 0.016 seconds.

2. Why Do We Use It in Our Code?

  • Different computers run games at different frame rates (fast vs. slow laptops).
  • Multiplying speed * delta_time keeps our Dinosaur, Cloud, and Cactus moving at the exact same speed on every device!

Movement Planning

How Does Each Sprite Move in Dino Run?

1. ☁️ Cloud: Which way does it move & does its height change?
• Moves Right → Left across the sky (center_x decreases).
• When it exits the left edge, it respawns on the right at a random Y height (170 to 210) so clouds appear at varied heights!
2. 🛤️ Ground: Which direction does the track scroll?
• Scrolls Right → Left at game_speed and leaps forward by WIDTH * 2 so the ground never ends!
3. 🌵 Obstacle: How does it move & does the cactus change?
• Moves Right → Left toward the Dinosaur.
• Once off-screen, it is deleted and a new random cactus (big or small) spawns on the right!
4. 🦖 Dinosaur: How does our hero move?
• Controlled by keyboard keys—jumping upward against gravity (and practicing left/right movement)!

Jump & Gravity Physics

Making the Dinosaur Jump with self.jumping

Why do we need self.jumping = False? It prevents infinite mid-air jumping! The dinosaur can only jump when not self.jumping (on the ground), and resets to False upon landing.
# In __init__: self.jumping = False
def jump(self):
if not self.jumping:
self.velocity_y = 430
self.jumping = True
# Updating the move function with the logic below
if self.jumping:
self.velocity_y -= 1200 * delta_time
self.center_y += self.velocity_y * delta_time
if self.bottom <= GROUND_Y:
self.bottom = GROUND_Y
self.velocity_y = 0
self.jumping = False
